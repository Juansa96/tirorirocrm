# Tiroriro Home CRM

CRM de ventas y producción de Tiroriro Home (React + TypeScript + Tailwind,
backend Lovable Cloud / Supabase).

Incluye el **panel del tapicero** (`/panel`): listado por cliente con prioridad
y retraso, ficha de detalle (silueta, plantilla de corte, imagen de referencia,
telas por tipo, extras, fechas y etiqueta de envío), acciones "tela recibida" /
"terminado", foto opcional del acabado y acceso por enlace con token.
